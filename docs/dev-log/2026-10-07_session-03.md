## Goal
Turn the demo into something that can earn money: research the name, patents and GB rules, make the game

## Decisions made
- **Name stays "Specimen Hunter".** "FISH ON!" is a registered US trademark of King Show Games (a slot maker)
  for slot machines and game software, so the brief rename to "Fish On!" was reversed. US register shows no
  live "Specimen Hunter" mark; UK IPO and EUIPO still to be checked (they block automated searches).
- **Route to money (in order):** 1) portfolio piece for paid slot work, 2) pitch/licence to a licensed studio or
  aggregator, 3) own UKGC licence only once there is income. Never take real-money play without a licence.
- **Outcomes decided before the reels move.** The engine now produces a whole round up front
  (`playRoundDetailed`), used by both the new game server and the in-browser demo.
- **Stake caps are operator settings:** the stricter of the operator's maximum and the GB age-band limit
  (£5 for 25+, £2 for 18 to 24).
- **Hosting: GitHub Pages** (chosen by Charlie). The static demo runs the engine in the browser, so the reel
  strips are visible to anyone; only the built game goes in the public repo, not the source, simulator or PAR.

## What changed (files, numbers, settings)
- `server/`: dependency-free RGS-style game server (sessions, stake caps, whole-pence wallet, idempotent

  game at http://localhost:8787 with outcomes from the server.
- `client/src/gameClient.js`: server mode / local mode; launch params `?age=18-24`, `?maxStake=2`; demo toggle.
- `client/src/engine.js`: `playRoundDetailed()`, `cryptoRand()` (Web Crypto). Engine tests now 7.

- `docs/legal/ip-and-regulatory-check.md`: trade mark, patent and GB regulation findings with sources.
- `docs/media/`: 97 s gameplay video (MP4, silent) and 7 full-HD screenshots.
- `docs/pitch/deck/`: source of the 12-slide pitch deck.
- `site/`: portfolio landing page + `build.sh` (builds the playable demo into `site/dist/play`).
- `GAME_NAME` in `client/src/config.js` renames the game in one place.

## Math results
- **Exact (from strips): RTP 96.142%** (base lines 54.140%, free spins 42.002%), trigger 1 in 151.70,
  E[free spins] 10.341, E[feature win] 63.72x, mean fish 3.052x.
- Simulation, 50,000,000 rounds (seed 2026): RTP 96.059% +/- 0.200, hit 25.50%, feature 1 in 152.1,
  SD 7.23, max 2,066.6x, cap never hit, returns below stake 11.14%. 100x+ 1 in 1,407; 1,000x+ 1 in 77,042.
- Excel line-win formulas match the engine's exact probabilities with zero difference.
