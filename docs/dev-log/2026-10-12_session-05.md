## Goal
Second polish pass from Charlie: new logos, update the desktop app, swap Pellets for Luncheon Meat, clean up the

that swoops in and helps you spot a big fish.

## Decisions made
- **Kingfisher (base game only), 1 in 300 base spins.** It flies in while the reels spin, then dives into 3, 4 or 5
  spots (60/30/10%) and turns them into Leather Carp wilds. It always takes **reels 2, 3 and 4 on one row**, so the
  paylines on that row get at least four of a kind: the event almost always pays (average 8.9x stake). A first
  version picked spots at random anywhere on reels 2-5; the test run landed five wilds on reels 4-5 and paid
  nothing, which would feel like a cheat, so the rule was changed.
- A Bite Alarm in a chosen spot stays an alarm, so the free-spins trigger rate is unchanged.
- **Paying for it:** reel 1 base strip loses one Luncheon Meat and one Bivvy (now a Float and Boilies), and the
  2lb 4oz fish weight goes to 396 (the free-spins strips are built from the base ones, so reel 1 changed there too).
- **Luncheon Meat** replaces Pellets: same pays and reel positions (internal name MEAT); re-exported strips were
  checked identical apart from the name before any other change.
- **Swims are baited by catapult**: it rises from the bottom, aims, and fires a pouch of boilies into each swim.
- **Logos:** an arched gold wordmark (header) and the same with a leaping mirror carp (title screen); new app icon
  and favicon drawn in code (`drawAppIcon` in art.js).
- Demo-only **DEMO KINGFISHER** button (free, removed in release builds, refused by non-demo servers).
