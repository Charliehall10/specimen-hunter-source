# Session 02 - 2026-10-07

## Goal
Turn the v0.1 prototype into a complete, polished demo game for the portfolio without changing the maths.

## Decisions made
- **Maths frozen.** Reel strips, paytable, fish weights and the 5,000× cap are unchanged. The engine only gained the cell positions of each winning line (for highlighting); its random-number use is identical.
- **Art direction:** UK lake at dawn (base game) turning to dusk (free spins). All symbols are drawn in code (Canvas2D), so there are no asset files, licences or brand names to worry about.
- **Anticipation:** when Bite Alarms land on reels 2 and 3, reels 4 and 5 spin 1.2 s longer with a red glow. Spins never get shorter than 2.5 s.
- **Big-win tiers:** Big Catch 15×, Huge Catch 50×, Monster Catch 200× stake. Only wins at or above stake are celebrated.
- **Reality check every 30 minutes**, with "keep playing" or "take a break" (ends the session and shows time and net).
- **Demo Bonus kept for demos**, but `npm run build:release` compiles it out completely.
- **Renamed the game "Fish On!"** (was working title "Specimen Hunter"). Files renamed to match: spec is now `docs/spec/fish-on-spec.md`, simulator is now `math/fish_on_sim.py` (run `python fish_on_sim.py ...` instead of `specimen_hunter_sim.py`). Trademark check now needed on "Fish On!" (a common angling phrase, so check for existing slot/game titles).
- **Later additions:** desktop app (Electron, `desktop/`, builds `FishOn.AppImage`), generated background music (calm base, livelier free spins, ♫/N toggle), big-win count-up now plays before the feature summary. A synthetic "Fish on!" voice line was tried and then removed.
- **Advertised max win still undecided.** The rules screen says only that wins are capped at 5,000× (true); no headline max-win figure is advertised.

## Math results (spins, RTP +/- CI, hit freq, feature freq, avg feature win, volatility, max win)
- JS engine check (`node src/verify.mjs 20000000`): **RTP 96.27% (95% CI ± 0.32%)**, hit 25.49%, feature 1 in 152, max 1,354×. Matches the Python reference (96.1%, 25.5%, 1 in 152).
- `npm test`: 5/5 pass (seeded RTP over 2M rounds within range, every line win checked against the grid and paytable).

## Problems hit and lessons
- `node --test src/` fails on Node 22 (it wants files, not a folder). Fixed by using `src/*.test.mjs`.
- Symbols looked jagged when shrunk on small screens. Fixed with mipmapped textures.
- Checked in a headless browser: title, base spins, line wins, a return below stake, anticipation, free spins, summary, Huge Catch, history, info pages, reality check and session end. No console errors.
